# ☕ Coffee Machine Digital Twin – Live Monitoring

A real-time coffee machine monitoring dashboard built with **Grafana** and **Microsoft SQL Server**.

## 📊 Dashboard Preview

![Coffee Machine Live Monitoring](Screenshot%202026-07-31%20065319.png)

## 🚀 Features

- Machine Status Monitoring
- ML1, ML2 and ML3 Flow Monitoring
- Temperature Monitoring
- Humidity Monitoring
- Power Monitoring
- Voltage Monitoring
- Signal (RSSI) Monitoring
- Last Update Tracking
- Machine Health Status
- Real-time dashboard visualization

## 🛠️ Technologies

- Grafana
- Microsoft SQL Server
- SQL
- Python
- Grafana Canvas
- Real-time Data Monitoring

## 🎯 Project Goal

The goal of this project is to create a **Digital Twin for a professional coffee machine** that provides real-time operational monitoring and machine health information through an interactive Grafana dashboard.
